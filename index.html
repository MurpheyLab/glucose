T1D Human-Controlled Insulin Demo

An interactive demo of glucose regulation based on the FDA-approved UVa/Padova Simulator, originally implemented in simglucose. It allows manual control of basal insulin, and loads virtual patients from the simglucose repository at runtime when available.
